# ShahadahAI

An "AI" chatbot with a dramatic personality, a niche sense of humor, and enough confidence to answer questions about faith, coding, life, and stress like it has a PhD in all of the above.

ShahadahAI is a lightweight browser-based chatbot built with plain HTML, CSS, and JavaScript. It doesn’t claim to be a cutting-edge AI model or a deep learning masterpiece. It’s much more honest than that: it’s a small, fun, rule-based project that responds to user input with some prewritten logic, a little sarcasm, and a lot of attitude.

This project was created for the kind of person who likes:
- spiritual reflections
- coding jokes
- life advice with a side of chaos
- chatbots that feel more human than they probably should

In short: it’s a tiny AI-inspired assistant with a personality disorder, but in a charming way.

---

## What it does

ShahadahAI responds to prompts and tries to match them to a set of predefined topics, including:

- Islam and the Shahadah
- Prayer and Quranic reflection
- JavaScript, HTML, CSS, and coding struggles
- Debugging and technical frustrations
- Life, anxiety, purpose, and existential panic
- Friendly greetings and casual conversation

It’s not trying to replace ChatGPT, Google, or your therapist. It’s simply a playful little project that gives witty responses in a browser, with a specific theme and a sarcastic tone.

---

## Why this project exists

Because someone looked at a basic web page and thought:

> “What if I made a chatbot that mixes faith, tech, and emotional support, and made it sarcastic enough to feel alive?”

And so ShahadahAI was born.

It’s not meant to be ultra-serious. It’s meant to be fun, expressive, and a bit chaotic — like a very opinionated intern with a keyboard and too much confidence.

---

## Project vibe

This project is built around the idea that:
- AI can be simple
- personality matters
- code can be playful
- a local chatbot can still feel oddly human

No backend. No API calls. No huge infrastructure. Just a little script, some smart enough logic, and a strong opinion about the meaning of life.

It’s a reminder that not every project needs to be a giant SaaS platform. Sometimes the best projects are just fun, weird, and unexpectedly meaningful.

The repo contains the core front-end files used to run the chatbot:

- `index.html` – the chat interface

The experience is intentionally minimal and focused, because sometimes less code means more personality.
